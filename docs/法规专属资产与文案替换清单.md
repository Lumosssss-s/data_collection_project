# 法规专属资产与文案替换清单（C4 · 施工图）

> **文档定位**：法规域残留资产的**文案级替换对照表**——LLM prompt 逐处改写、前端文案、数据资产文件、错误提示、统一术语词表。C1 回答"哪个文件改什么"，本文档回答"每处文案换成什么"，供实施时逐条核对与全局残留扫描。

## §1 内联 LLM Prompt 替换对照（9 处）

> 项目无独立 prompt 文件，全部内联。下表「现状角色 → 医疗版角色」为改写方向；输出结构约束（JSON Schema / 流式格式）沿用各自现有实现。

| # | 位置（已核实行号） | 现状 prompt 角色 / 要求 | 医疗版替换方向 | C1 落点 |
|---|---|---|---|---|
| PR-01 | `services/abstract_service.py` L53-72 | 中文 150~300 字法律摘要（立法目的 / 核心内容 / 适用范围） | 指南 / 文档摘要（发布机构 / 适用癌种与分期 / 核心推荐要点 / 版本年份），长度约束沿用 | BE-22 |
| PR-02 | `services/kg_extraction_service.py` L119-171 | "你是一位法律知识工程专家"，法条 → 法律实体/关系三元组（JSON） | "你是肿瘤医学知识工程专家"，推荐条目/疾病档案 → 医学三元组（本体 = 六类实体 + 九类 relation，§5.7.3） | BE-20 |
| PR-03 | `api/v1/compare.py` L57-85 | "跨境法律合规专家"，两法域法规差异（差异总览 / 对比表 / 关键差异 / 合规建议） | 双模式：**方案对比**（适应证/疗效/不良反应/证据等级/费用）与**疾病对比**（鉴别要点）；输出四段结构沿用 | BE-08 / BE-19 |
| PR-04 | `services/query_decomposer.py` L115-136 | 法规检索子查询拆分助手 | 临床问题拆分助手（癌种 / 分期 / 分子 / 治疗线数四维，PICO 式），多路检索框架沿用 | BE-16 |
| PR-05 | `services/qa_service.py`（多轮问答主 prompt） | 法规问答：答案基于检索到的法条，含法域引用 | 循证问答：答案基于检索到的推荐条目，**每句携带 [来源: 指南 版本 章节] 标注 + 证据等级**；拒答策略强化（知识库无依据时明确拒答，§4.3 原则 4） | BE-17 |
| PR-06 | `services/summary_service.py` | 法域 / 合规要点总结 | 癌种诊疗要点 / 疾病速览卡（概述 + 就医指引，患者端联动） | BE-23 |
| PR-07 | `services/topic_analysis_service.py` | "比较法研究专家"（跨法域专题） | 跨癌种专题分析（如 PD-1 抑制剂在各癌种的适应证与证据），输出结构沿用 | BE-27 |
| PR-08 | `services/structured_analysis_service.py`（分析 prompt 族） | 法规结构化分析（含缓存指纹维度） | 医疗专题 / 对比结构化分析，指纹维度随 C2 缓存字段（target_a/b）调整 | BE-24 |
| PR-09 | `services/similar_law_service.py`（相似检索辅助） | 相似法规判定 | 相似推荐条目 / 相似疾病判定（疾病详情页"相关疾病"） | BE-28 |

**Prompt 改写通用原则**（全部适用）：
1. 安全前置：所有面向用户的生成 prompt 加入"仅基于检索结果作答、不构成诊疗建议、定位辅助参考"约束（主方案 §4.3 / §10 医疗幻觉对策）；
2. 术语约束：生成中出现的疾病 / 药品名一律使用术语字典 canonical（G9），prompt 中显式注入术语约束；
3. 患者版专用：凡输出给患者端的（PR-06 速览卡等），附"通俗改写 + 句均 ≤40 字 + 专业词括注"要求（§5.7.2-3）。

## §5 停用模块残留字段记录（D-03 定案附件）

C1 D-03 已定案：`api/v1/mapping.py` 与 `services/mapping_service.py` **赛程内不实施、入口保留**。本节冻结记录其法规字段快照，供赛后扩展"多指南推荐对照"时参考（也是残留扫描的**白名单依据**）：

| 文件 | 残留法规字段（冻结） | 赛后扩展映射 |
|---|---|---|
| `api/v1/mapping.py` | `source_jurisdiction` → `target` 条款 KNN 映射入参 | `source_guideline` → `target_guideline` 推荐对照入参 |
| `services/mapping_service.py` | 条款级 KNN + 相似度阈值逻辑（通用算法，无领域词为主） | 算法直接复用，仅换字段名与调用方 |

> **白名单规则**：残留扫描时这两个文件内的"法域/jurisdiction"字样**豁免**（已冻结记录）；前端 topic 页若残留 network-graph 引用 mapping 接口的调用，随 BE-10 改造一并处理（不豁免）。

## §6 统一术语替换词表（全局口径）

> 实施顺序建议：**先改此词表相关结构（C1）→ 再全局搜索替换（本表）→ 最后跑残留扫描（§7）**。词表是 C1/C4 的公共契约，前端后端必须同口径。

| # | 法规域术语 | 医疗域替换 | 备注 |
|---|---|---|---|
| 1 | 法规 / 境外法规 | 指南 / 指南文档（泛指时用"文档"） | 数据类区分：guideline / standard / consensus |
| 2 | 法域 | 癌种 | 枚举五值（lung/breast/colorectal/gastric/thyroid） |
| 3 | 条款 | 推荐条目 | 检索主单元 |
| 4 | 跨法域 | 跨癌种 | 专题 / 对比场景 |
| 5 | 法条引用 [来源: XX法 第X条] | [来源: CACA 2025 肺癌 第 3.2 节] 式指南引用 | 含版本 + 章节 breadcrumb |
| 6 | 法律主体 / LegalSubject | 医学实体（六类：disease/drug/examination/symptom/gene/staging） | 图谱本体 |
| 7 | 合规要点 / 合规建议 | 证据等级提示 / 循证要点 | compare 输出段 |
| 8 | 立法目的 / 适用范围 | 适用癌种 / 适用人群（population）/ 临床场景（scenario） | 摘要与条目字段 |

| 10 | 法规主题 taxonomy（金融监管等） | 医疗 taxonomy（癌种 / 文档类型 / 场景三级） | 分类资产 |
