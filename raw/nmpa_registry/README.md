# nmpa_registry 国家药监局注册信息（人工查询样例）

NMPA 数据查询页（`https://www.nmpa.gov.cn` / `datasearch.nmpa.gov.cn`）对脚本与自动化浏览器均返回 HTTP 412（WAF），只能人工查询后导出/打印，本目录存放人工查询样例。

## 文件

| 文件 | 药品 | 批准文号 | 说明 |
|---|---|---|---|
| `nmpa_registry_alectinib_HJ20180047.pdf` | 盐酸阿来替尼胶囊（安圣莎 / Alecensa） | 国药准字HJ20180047 | 境外生产药品注册信息查询页打印件（4 页） |

## 能查到什么（也是本目录的唯一用途）

注册证号/原注册证号、产品名称（中文/英文）、商品名（中文/英文）、剂型、规格、包装规格、上市许可持有人、生产厂商及地址、发证日期与有效期、境内责任人、药品本位码、产品类别。

## 查不到什么（关键限制）

**没有说明书正文**：适应证、用法用量、禁忌、不良反应、相互作用均不在查询页内。因此 A4 的中文四段不能依赖 NMPA 查询页：

- 适应证、标准用法用量与调整、相互作用 → 由 `tools/20_guideline_drug_extract.py` 从《新型抗肿瘤药物临床应用指导原则（2025年版）》抽取；
- 禁忌、不良反应（含频率）→ 暂用 openFDA 英文 interim（`label_en_interim`），待人工按说明书补；
- `approval_no`、商品名、剂型、规格、持有人 → 按本目录样例版式逐药人工查询后录入 `raw/nmpa_labels/labels_zh.json`（19 号脚本校验合并）。

## 录入注意

1. 批准文号区分「国药准字H/Z/S/J…」与境外「国药准字HJ…」，按查询页原文录入，不要补零或改格式。
2. 一个药品可能有多个批准文号（不同规格/分包装），`approval_no` 取主规格，其余写入 `annotation`。
3. 规格与剂型以查询页「规格（中文）」「剂型（中文）」为准，可与 FDA NDC 字段交叉核对。
